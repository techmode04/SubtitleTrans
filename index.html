# SubtitleForge — AI SRT Translator

SubtitleForge is a high-performance, browser-first tool designed to translate .srt files into multiple languages concurrently using AI.

## Features
- **Fast Batch Processing:** Caches successful batches to save API calls.
- **Concurrent Translation:** Translates up to 3 languages simultaneously.
- **Hinglish Optimization:** Specialized 2-step pipeline for natural Roman Hindi.
- **Local Generation:** All SRT and ZIP files are generated locally.

Developed by **Sachin Dhisle**

## Security
For production deployment, ensure the Gemini API calls are routed through a secure serverless function.
